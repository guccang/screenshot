# 轻截图（Windows）

双击 `Screenshot.exe`，程序会常驻系统托盘。默认快捷键 **Ctrl+Alt+A**。

1. 拖动鼠标框选区域，松开后图片自动复制到剪贴板。支持多显示器；Esc 或右键取消。
2. 切换到聊天或文档，按 Ctrl+V 粘贴。退出程序后仍可粘贴。
3. 右键托盘图标，选择“查看 / 保存上次截图”，再点击“保存”或按 Ctrl+S，选择本地 PNG 保存位置。可对同一截图同时复制和保存。
4. 关闭预览不会退出后台程序；右键托盘图标选择“退出”。通过托盘菜单的“设置…”修改全局快捷键，保存后立即生效并记住。快捷键冲突时可双击托盘截图。

不联网、不上传截图。暂不提供标注、录屏、自动开机启动。受保护的视频及安全桌面可能无法截图。

## 从源码构建

Windows 自带 .NET Framework 4.x 环境，无第三方依赖：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## 手动验收

- 后台按快捷键，正向/反向框选，Esc 取消。
- 在跨屏区域框选，核对预览尺寸与像素内容（包括不同缩放比例的屏幕）。
- 复制后在画图中粘贴；退出截图程序后再次粘贴。
- 保存 PNG 并重新打开，检查图片内容。
- 重复启动只保留一个实例；托盘退出后快捷键释放。
